# Step: OpenCV Revision Flashcards

## Description

Seven flashcards for quick revision of core OpenCV vocabulary, including OpenCV itself, pixels, NumPy arrays, BGR, grayscale, Canny, and thresholding.

## Type

flash_card

## Duration

10m

:::flashcard

front: "What is OpenCV?"

back: "An open-source library for computer vision and image processing, originally developed by Intel and widely used with Python."

:::

:::flashcard

front: "What is a pixel?"

back: "The smallest unit of a digital image, storing a numeric value representing brightness and/or color at that point."

:::

:::flashcard

front: "What is a NumPy array, in the context of OpenCV?"

back: "The multi-dimensional data structure OpenCV uses internally to store image data, with shape (height, width, channels)."

:::

:::flashcard

front: "What does BGR stand for?"

back: "Blue, Green, Red — the default channel order OpenCV uses when reading and storing color images."

:::

:::flashcard

front: "What is a grayscale image?"

back: "A single-channel image that stores only brightness values (0–255) with no color information."

:::

:::flashcard

front: "What is the Canny edge detector?"

back: "A multi-stage algorithm that detects object boundaries in an image by locating and refining areas of sharp intensity change."

:::

:::flashcard

front: "What is thresholding?"

back: "The process of converting a grayscale image into a binary (black-and-white) image based on whether each pixel is above or below a cutoff value."

:::
